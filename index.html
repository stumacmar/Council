Meet the Council

Seven specialist AI agents that each analyse your decision from a distinct perspective — then synthesise into a single verdict.

View on GitHub Get started

How it works

1

Ask a question

Type /council followed by any decision in Claude Code.

2

7 agents analyse in parallel

Each specialist examines the question from their distinct perspective simultaneously.

3

Agents write to a shared file

Every agent appends their analysis to shared_reasoning.md with a vote.

4

Council is synthesised

A vote table, consensus map, and final PROCEED / DO NOT PROCEED verdict are produced.

The agents

🟢
Optimist
Identifies opportunities, upside scenarios, and favourable conditions.
What could go RIGHT?
🔴
Devil's Advocate
Stress-tests assumptions, surfaces failure modes and hidden risks.
What could go WRONG?
🟡
Realist
Assesses practical feasibility — resources, timelines, and blockers.
Is this actually FEASIBLE?
🔵
Strategist
Evaluates timing, opportunity cost, and strategic direction.
Is this the right move NOW?
🟣
Stakeholder Advocate
Maps who is affected and gives voice to those not in the room.
Who is AFFECTED and how?
⚪
First Principles
Strips back to fundamentals and challenges the framing of the question.
Are we asking the RIGHT QUESTION?
📚
Historian
Brings precedents, patterns, and lessons from similar past decisions.
Has this been tried BEFORE?

Usage

Full council — all 7 agents
# Major decisions — board, property, finance, restructuring
/council Should we restructure the finance function before the audit?
/council Is this the right time to make an offer on the Hexham property?
/council Should we proceed with the France motorhome trip in July given the budget position?
Quick council — 3 agents, faster
# Lower-stakes or time-sensitive decisions
/council-quick Should I upgrade the Bürstner's bike rack before the trip?
/council-quick Which campervan insurance provider should I renew with?

Example output

Council Decision Analysis

Question: Should we restructure the finance function before the audit?
Agent Vote Confidence Key point
🟢 Optimist PROCEED Medium Clean structure signals maturity to auditors
🔴 Devil's Advocate DO NOT PROCEED High Restructuring mid-audit creates process gaps
🟡 Realist PROCEED WITH CONDITIONS High 6–8 weeks minimum; not enough runway before Q3
🔵 Strategist PROCEED WITH CONDITIONS Medium Right direction, wrong timing — defer to post-audit
🟣 Stakeholder Advocate DO NOT PROCEED High Finance team uncertainty will harm audit cooperation
⚪ First Principles PROCEED WITH CONDITIONS Medium Real question is whether the restructure is decided — not when to announce
📚 Historian DO NOT PROCEED High Pre-audit restructures consistently increase audit scope
Final recommendation
PROCEED WITH CONDITIONS

Defer the restructure until after the audit completes. Lock the decision and communicate intent internally now to retain key staff, but hold implementation until Q4. Three of seven agents voted Do Not Proceed on timing grounds; the council agrees the restructure is directionally correct but the timing creates unnecessary risk.

Get started

Per project
Global
Terminal
# Clone Council
git clone https://github.com/stumacmar/council.git

# Copy .claude/ into your project
cp -r council/.claude /path/to/your-project/

Claude Code discovers agents and commands automatically when you run it from the project directory.

Terminal
# Clone Council
git clone https://github.com/stumacmar/council.git

# Install globally — available in every project
mkdir -p ~/.claude/agents ~/.claude/commands
cp council/.claude/agents/* ~/.claude/agents/
cp council/.claude/commands/* ~/.claude/commands/

Global install makes /council available in every Claude Code session on your machine.

Tips

📁
Build a decision log. Save each shared_reasoning.md to a /decisions/ folder as an audit trail — invaluable for board reviews and post-mortems.
⚡
Agents run in parallel. A full seven-agent council takes roughly the same time as a single agent response — don't save /council-quick for time reasons alone.
🎯
Strategist + First Principles are the most valuable pair for board-level decisions. Stakeholder Advocate is critical for anything involving organisational change.
📱
On mobile, create a Claude Project with the council prompt in its instructions — you get the same structured output without needing Claude Code.
🔍
Need just one view? Invoke any agent directly via Claude Code's Task tool — e.g. ask the Historian alone when you need a precedent check without the full council.
